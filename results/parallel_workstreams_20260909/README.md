## 科研子项目与后续优先级

这四个材料方向共享 VACE 和证据接口，但应分别建立假说与验收，不能把不同材料的指标混成一个“成功率”。下表是后续研究排程，不代表已经启动推理或冻结新实验。

| 研究方向 | 当前证据 | 下一项可证伪问题 | 最小实验与停止条件 |
| --- | --- | --- | --- |
| 块状食物／蛋糕承载 | 两组预切块提起，有缺口；接触仍不明确 | 显式叉面接触控制是否改善承载关系？ | 固定输入、种子、预算与合成范围，只改变接触控制；动作、接触、自然度独立判断。无明确接触改善则记录负结果，不换种子挑图 |
| 液体／汤匙容纳 | 两组有携液动作；硬边、平液面仍明显 | 缺陷主要来自控制图硬边还是原生生成？ | 先比较现存控制、raw 与 projected 的同帧局部，定位后才拟定单因素试验；无法定位则不启动调参 |
| 离散食物／炒饭来源变化 | 两组载荷移动，铲面框状、来源减少含糊 | 单独改善来源区域控制能否保留米粒且产生对应减少？ | 分开记录载荷、接触、来源，不允许只看被举起的区域；来源指标或自然度退化时不宣称整体改善 |
| 柔性食物／面条连续与夹持 | 运动范围合成修复有证据，双筷识别仍不稳 | 观察器能否独立分辨两根筷子及真实夹持？ | 先用独立标注、擦除和色块反例验证观察器；不通过则不得接入扩散引导，保留为独立方法研究 |

发表前优先使用已核验材料，补充诚实解释和评价工具；新的算法有效性研究不应挤占报告与演练。上述候选方案尚非预注册：运行前必须再确定主指标、判定阈值、样本／种子、修改文件及哈希，并冻结新版本。当前不凭空指定一个阈值来适配已看过的结果。

## 执行门槛与串并行边界

- CPU 证据审计、工具开发、文字材料可以并行；共享 GPU 不因子代理数量而被分配为并行任务。
- 当前不恢复自动心跳，不远端启动推理，不下载模型，不上传 GitHub 或公开图片。
- 未来执行仍需先审计 gp38–gp42；仅 RTX A6000 满足空闲显存 ≥48000 MiB、利用率 ≤5%、零计算进程、主机可用内存 ≥80000 MiB 才可准入。快照不等于独占预约。
- 使用新输出根目录和新预检路径，保留全部技术失败；不得占用、修改或终止他人进程。条件优先串行。
- 新实验依赖顺序：证据缺口 → 单因素假说与可用指标 → 冻结配置 → 资源审计 → 执行 → 原始结果核验 → 独立语义评审 → 再更新主张。

## 已知事实与结论边界

汤、炒饭、蛋糕共六个条件已完成；原 Day19 八条件任务仍为保留的技术失败，不能将补齐非面条条件说成八条件成功。单图、单种子与混合真实／合成输入不能证明泛化。投影前区外零差异来自合成，不是模型自主保护背景。当前未建立相对3D的稳定语义优势、新扩散算法有效性、物理正确性或照片级真实感。

两页报告保留为此前已完成排版核验的独立交付，本轮不改写。汤和炒饭的来源限制仍有效，公开发表或公开仓库发布前需核对图像授权。计划中的创作效率、观看趣味等收益均未完成用户验证。
