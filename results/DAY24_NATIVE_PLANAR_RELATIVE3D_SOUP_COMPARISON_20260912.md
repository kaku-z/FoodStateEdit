# Day 24：Native / Planar / Relative-3D 汤例对比

## 第二项结论

第二项比较已完成，不需要新增 GPU 推理，因为三个冻结条件都已有同图、同 seed、同 VACE 预算的结果。

| 条件 | 勺子 | 载荷 | 来源变化 | 照片自然度 | 判定 |
| --- | --- | --- | --- | --- | --- |
| Native input + text/mask | 无 | 无 | 无 | 原图保持自然，但没有动作 | 动作失败 |
| Planar proxy + VACE | 有 | 有汤液 | 不清楚 | 勺缘和手柄偏合成 | 部分动作成立，照片失败 |
| Relative-3D proxy + VACE | 有 | 有汤液 | 不清楚 | 勺缘和手柄偏合成 | 部分动作成立，照片失败 |

固定检查第 0、3、6、10、15、20 帧。Native 六帧都没有生成勺子；Planar 和 Relative-3D 都提供了接近、接触和抬起的明确运动支架。由此，本开发例支持“需要显式运动代理”，但不支持“Relative-3D 明显优于 Planar”：两者最终图和动作序列非常相近，且都没有解决照片感和来源对应。

因此论文中可写：提示词和编辑范围本身不足以触发该汤例动作，显式交互控制是必要组件。不能写：本实验已经证明 3D 控制优于 2D 控制。后者仍需多张未见图、固定三 seed 和盲评。
