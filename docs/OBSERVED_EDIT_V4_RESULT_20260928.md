## 结论

**修复方向是：只约束可信的食物内部，让边缘、阴影和工具接触处共同生成，并在采样末期解除约束。** 已在 gp40 完成两个条件、两张真实输入图的四次生成。新图没有经过最终像素贴回或泊松融合。

与 v3 强约束 raw 对照，玉米的明显白圈和旧位置凸起状亮斑在两种 v4 结果中不再可见；披萨图中其他食物周围的块状边缘也不再可见。代价是背景改动增多，披萨旁边还出现了一小块多余碎屑。因此这是有证据的局部修复，**当前方案仍未达到完整编辑任务的通过标准**。

与相同输入的无约束生成相比，v4 的主要收益是内部纹理保留，特别是披萨。玉米整体观感与无约束基线接近。高通 `detail` 分支没有显示出稳定优于更简单 `interior` 分支的证据；后续优先保留 `interior` 作为开发候选，无约束基线继续保留。

## 为什么这样修改

食物身份不能直接等同于固定原图的全部像素。搬动后，边缘、遮挡、接触阴影和局部亮度需要变化；强制恢复这些位置，会让生成状态与固定状态互相冲突。v3 还固定了背景，使源处阴影和解码边界难以协调。

本轮共同修改如下：

1. 只输入一个一致的搬运后状态，输入图片和提示词与 v3 相同。
2. 食物边缘内 12 像素不施加约束，12–24 像素逐渐增加内部权重；保留其他食物时使用前景分割，避免连同矩形中的餐盘和阴影一起固定。
3. 内部最大约束强度为 0.8；最后四分之一步骤逐渐减弱，最终一步为零。
4. 背景、边缘、工具和阴影交给同一个生成过程，不做输出像素恢复。

下一步噪声水平的参考为 `known = (1-sigma_next)*clean_reference + sigma_next*initial_noise`。两个分支分别为：

```text
interior: z <- z + a(t) C (known-z)
detail:   z <- z + a(t) C [(known-z)-G5(known-z)]
```

`C` 是距离边界定义的内部软权重；`G5` 为潜变量网格上的 5×5 均值滤波。距离边界只是一种置信度启发式；潜变量高通分量不等同于物理反照率，也不能保证语义身份。

v3→v4 同时改变了约束区域、强度和释放时序，本批只能检验这组修改的效果，不能分别确定白边消失由哪一项造成。模型、输入、提示词、seed 和采样参数相同，减少了其他差异。

## 完整数值结果

两张图均为已见 Nutrition5k 开发图片；seed=281，40 步，CFG=4，输出 1184×896。对全部 raw 图统一缩放至 640×480 后测量。MAE 使用 0–255 RGB 单位，越低越好；纹理相关性越高越相似。没有挑选 seed、失败重试或只展示最好结果。

指标解释：

- **源位置 MAE**：原食物掩码内，相对真实“添加该食物之前”的餐盘照片。它只验证移除区域，不是托举后完整图像的真值。
- **源位置周边 MAE**：源掩码膨胀 48 像素后的环带，排除保留食物及计划工具区域的邻域。本轮在输出前固定的新诊断，并非旧协议已有终点；它是几何邻域，不是真实阴影标注，部分覆盖餐盘边缘和桌面。
- **远处背景 / 保留食物变化**：相对输入原图。背景区域排除源区域、工具和保留食物的扩展邻域；保留食物使用分割前景。这两个区域与 v3 旧报告中的背景区域/保护矩形不同，跨报告数值不能直接相减。
- **目标内部 RGB / 纹理相关性**：相对搬运状态参考，只测目标内部满权重像素。纹理相关性为逐通道去均值后的 RGB 相关性，不是独立身份识别器；不检查全食物形状、边缘或新增碎屑。

披萨 interior 的纹理相关性从无约束的 0.9567 提高到 0.9959，保留食物变化从 9.766 降到 5.358；但远处背景变化 11.381 仍远高于旧强约束的 0.663。玉米源位置周边误差从旧强约束 5.855 降至 3.777，视觉上明显的白圈/亮斑消失。局部指标与完整画质必须一起判断。

## 剩余问题如何继续解决

以下是基于本批结果的下一阶段设计，**尚未实现或验证，不算本轮结果**：

1. **背景漂移**：将影响区域从“食物掩码”扩大为“源食物及旧阴影、目标食物及新阴影、工具接触区”的并集。只对远离这些区域的背景施加平滑、有限强度的约束，仍保留过渡带和末期释放。需要单独消融背景约束，不能同时更改食物约束后再归因。
2. **新增碎屑**：增加全图食物实例与源块对应检查，检测目标之外新增的食物区域；用单独标注的小碎屑样本验证检查器，不能用目标内部 NCC 代替。检查失败的输出必须计为失败。若尝试局部重生成，应预先固定修复次数并报告全部调用，而不是无限重抽直到看起来成功。
3. **完整身份与泛化**：在开发集固定通过条件，同时覆盖食物结构、额外实例、旧阴影、边缘、背景和工具接触。完成开发后再一次性运行封存测试，多 seed 报告失败比例；当前两张图不能支持成功率或显著性结论。

如果目标进一步要求真实三维、真实托举高度或物理质量守恒，需要额外观测或真实托举配对验证。增加算力可以支持更多假设和搜索，但不会补出单图中未观测的真实状态。本轮没有将这些不可验证的主张当作解决二维伪影的前置条件。
