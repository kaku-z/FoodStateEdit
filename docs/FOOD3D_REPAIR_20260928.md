# 第一口三维几何问题定位与修复

## 本次完成的范围

在 gp40 上，对同一张真实 UECFOOD 豆腐照片 `7489.jpg` 完成了可见面约束、局部切取、抬升及叉子静态支撑的修复实验。最终结果目录为 `outputs/food3d_repair_20260928/server_results/results/repair_v5/`。

当前产物是具有源图纹理的三维代理和诊断合成图，**尚不是达到照片真实感要求的最终进食图**。没有调用 Qwen 或 VACE，没有添加手或人物。新方案用块状豆腐先验替代了本例中不可靠的自由形状生成结果；不是把原 Hunyuan 网格平滑一下，也不是证明 Hunyuan 本身已经修好。

## 原因与代码修改

1. **姿态歧义。** 旧 `register()` 只最大化轮廓 IoU，并允许自由三维旋转。错误的一面也可能匹配外轮廓。现在对原始完整照片运行 MoGe，获得预测内参、可见点图和法线，以三个源图语义锚点区分顶面、左侧面和右侧面；联合拟合点到面距离、法线方向及双向轮廓距离。相机不再自由旋转去追轮廓。
2. **食物形状没有受到材料约束。** Hunyuan 输出虽经精确零面积面清理可用于布尔运算，但表面折皱和棱角变形不适合这块豆腐。现在显式使用闭合、正交块体先验。它牺牲了局部圆角与不规则细节，换取稳定的可见面对应及可操作体积；仅用于这类块状食物。
3. **体积比例不能定义一口。** 旧 `split_and_lift()` 用无限切平面截出约 6% 体积，产生长楔形或薄片。现在由局部立方体与同一个食物实体求交得到取食块，剩余部分是严格的集合差。边长为较短水平边的 0.32 倍，因此体积比例由尺寸自然决定，约为 2.49%。这不等于实际厘米或人类适口尺寸。
4. **餐具没有参与约束。** 现在构建闭合的四齿叉子实体，让叉齿上表面与块底接触；检查接触斑块、均匀密度下的重心支撑、最终姿态中的体积穿透。切块和餐具共享目标姿态，不依靠图片模型猜接触关系。
5. **抬升方向由手工相机角度定义。** 现在由预测顶面法线确定向上方向，要求块底高于原食物顶部 0.18 倍食物最大边长，再搜索水平位移使结果留在画面中。食物底面是几何先验，不能称作实测盘面。

主实现：`scripts/repair_food3d_first_bite.py`。同图误差敏感性：`scripts/validate_food3d_repair.py`。旧代码与两份原始生成网格保留，不覆盖。

## 误差敏感性检查

8 组固定检查全部完成：原设置、坐标单位乘 0.5／2、掩码腐蚀／膨胀 3 像素、焦距乘 0.9／1.1，以及法线俯仰方向增加 3°。焦距变化时同步变换点和法线，使像素投影一致。

- 任意单位变化时，姿态差小于 0.002°，归一化尺寸变化小于 0.00002，说明结果基本不依赖预测单位的任意取值。
- 掩码 ±3 像素时，姿态变化不超过 0.20°，归一化尺寸最大变化约 0.0153。
- 焦距 ±10% 时，姿态变化不超过 0.24°，归一化尺寸最大变化约 0.0415；可见尺寸仍存在内参不确定性。
- 法线扰动 3° 时，姿态变化约 0.88°，归一化尺寸最大变化约 0.0203。
- 8 组都通过闭合、互补分割、最终静态接触及无体积穿透检查。

这是同图开发敏感性检查，不是统计置信区间、多食物测试或独立泛化评价。

## 纹理与运行问题

原图颜色按相机投影映射到原先可见的表面，移动块携带相同纹理坐标。新暴露的切面使用显式推定的三种方向明暗材质；不能从单张照片恢复其真实内部纹理。新暴露背景共 2,751 像素，使用 Telea 小区域填补，填补掩码单独保存。没有生成投影阴影、断裂纹理、金属反射或豆腐形变，因此合成图仍有明显的图形渲染痕迹。

原位纹理回投影检查的颜色平均绝对误差为 1.75／255，通过小于 12／255 的检查阈值。这只验证纹理映射及颜色接口没有把照片变黑或错位；因为纹理由源图投影得到，不能用该误差证明几何正确。

保留了全部技术失败及逐次脚本：

- `repair_v1`：网格顶点只读，原地减法失败；改成显式新数组。
- `repair_v2`：PyOpenGL 3.1.0 在 Python 3.12 下创建纹理时发生 ctypes 类型错误；用独立 `compat_packages` 安装 3.1.7，不改原有 Qwen/VACE 环境。
- `repair_v3`：整数 `[1,1,1]` 被颜色接口当作字节值，导致环境光过暗；改为浮点 `[1.0,1.0,1.0]` 并显式设置白色材质因子。
- `repair_v4`：运行完成，但均匀切面材质使凹口缺少深度线索；最终 `repair_v5` 加入方向明暗与原位纹理回投影颜色检查。

结果目录拒绝覆盖。MoGe 模型推理仅运行了一次；修复渲染与几何时复用同一份点图、法线和内参。原图、深度图、代码、原始失败、结果、模型版本与运行依赖均归档；模型权重保存在服务器，不重复打包。

已经排除了本例中的自由姿态错配、无限平面薄片和无餐具支撑问题。尚需解决的是圆角及非规则表面保真、切断后的真实材质、阴影与反射、柔软食物形变，以及在其他食物上的验证。动作插入过程未建模：当前检查只覆盖抬升后的静态姿态，不能证明叉子能沿无碰撞路径插入并切下该块。这个阶段不能宣布完整的真实“吃第一口”生成任务已完成，也不能将这些标准几何约束直接声称为已验证的论文原创贡献。
