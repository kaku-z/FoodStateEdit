## 修正后的方法与验证顺序

以下为下一实现的要求，尚未执行新的模型实验：

1. **先表示离盘运动。** 显式定义餐盘平面、相机、食物和勺子的支撑关系；以沿盘面法线的位移 `h*n_plate` 控制食物与勺子的共同抬升。若几何来自估计，必须标为假设；没有尺度标定时使用相对餐盘尺寸，不能声称厘米高度准确。
2. **从几何产生图像控制。** 将抬升后的几何投影为轮廓、深度顺序、法线和投影阴影，允许透视大小、可见侧面和遮挡随运动变化。食物身份约束应跟随新的表面对应关系，不能继续固定旧二维轮廓。接触阴影约束用于食物与勺子；餐盘上的投影由悬空几何和光照假设产生。
3. **先做零高度与正高度对照。** 在其余条件一致时比较 `h=0` 与至少两个正高度。先检查几何控制图确实变化，再检查原始生成是否跟随高度控制。几何渲染自身正确，不代表生成器已经遵从。
4. **先通过“看得出抬升”。** 保留当前失败样例；另用能看清盘面、工具及离盘关系的斜视真实开发图验证。判据是工具与食物构成同一被托起的整体、盘面与其关系清楚、投影和遮挡一致。原俯视输入仍需单独验证，不能用容易的视角替代原任务。
5. **通过后才优化纹理。** 没有通过抬升视觉检查的输出一律计失败，不能用低 MAE、高纹理相关性抵消。随后才评价食物身份、额外碎屑和背景保持。
