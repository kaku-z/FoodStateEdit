# 真实照片上的第一口食物：完整实验记录

> 状态：实验、复跑、逐图诊断复核、检测和交付校验均已完成。192 个预定条件，174 张生成图，18 个预处理失败，正式生成技术失败为 0。完整完成不等于方法有效。

本次结果不支持“加入当前三维代理和潜变量约束即可稳定提升第一口图片生成”的假设。Qwen 直接编辑完整通过 5/24，三维代理细化为 2/24，再加分阶段约束为 1/24；VACE 四种设置均为 0/24。这里的完整通过来自一个未盲化的助手诊断复核，不能写成人类评测或总体成功率。

本实验的目标是入口前的瞬间：一小口食物由餐具从下方托住，明显离开盘面，原食物出现对应缺口，保持原照片的食物、餐盘、光照与构图，不出现人手或人物。实验范围是单块豆腐，不外推到面条、米饭、碎菜或所有食物。

## 实验要回答的问题

1. 显式三维切取、抬升和承托规划，加上生成模型的外观细化，是否比直接编辑或二维食物贴片更容易同时满足全部要求？
2. 在三维代理图已经作为主输入时，额外的分阶段潜变量约束是有帮助，还是把灰色餐具和人工切面一起锁死？

第二个问题允许负面答案。开发阶段已经观察到过强约束损害真实感。不能把“几何约束成立”“生成出图”与“真实的第一口图片成功”混为一谈。

## 实际执行的算法

MoGe 预测可见表面的点、法线和内参。对食物掩码内的三个面聚类，拟合一个闭合的正交块体，同时约束可见面和平面投影轮廓。隐面由块状豆腐先验补全，未被测量。

在同一闭合实体 S 上做局部立方体布尔切取，得到第一口 B 与剩余部分 R。B 与 R 的体积划分、相交体积、连通性、闭合性在三维代理内部检查。随后刚性移动 B，令其底面比原食物顶面高 0.18 倍食物最大尺寸 L。叉齿从下方接触 B，检查质心投影落在接触支撑区域内，且与剩余食物不相交。该设计是静态、均匀密度的刚性接触，不模拟豆腐破裂、形变、摩擦或动态插入。

可见食物表面投影回原图纹理，新增切面用简单方向性色调表示，再投影出目标 RGB、第一口、餐具、接触区与缺口掩码。Qwen 的主输入是已经完成切取和抬升的代理图，原照片为第二张外观参考图；它负责把切面与餐具细化成照片外观。VACE 使用相同目标控制图、编辑区域和原照片参考。VACE 是这里的条件生成后端，不提供三维重建。

额外约束 D 在去噪过程中把局部潜变量向带同一初始噪声的目标代理潜变量拉近。Qwen 对刚性餐具和接触区使用完整局部更新，对食物与缺口使用低频更新，并提前释放。VACE 使用现有 GeoEdit TTM 实现，延迟释放餐具/接触约束。两者的实现和时间表不同，不声称是完全相同的后端算法。

本次可检验的自定义部分是任务特定的几何实体切取、承托规划、代理输入组织和约束调度。MoGe、Qwen、VACE、GeoEdit TTM、布尔几何与普通投影本身均为已有组件；本实验不把组合直接认定为已验证的新颖论文贡献。

固定种子为 41、163、907。每个后端 8×4×3=96 个条件，总计 192。06 三维拟合在正交坐标系手性检查处失败，B/C/D 的 18 个条件记为预处理失败；A 仍运行。因此实际模型调用为 174 次。没有换图，也不从分母删掉失败。

Qwen 使用 Qwen-Image-Edit-2511，40 步、true CFG 4，单张 640×480 输出。VACE 使用 Wan2.2-VACE-Fun-A14B，30 步、CFG 5、控制强度 1，以单帧 0 为固定结果。开发阶段另做了 9 帧测试，固定取第 4 帧，没有挑最好看的帧。正式原始图不进行像素级背景回贴或其他合成后处理。

D 的 Qwen 调度固定为：刚性区 max=0.35、hold=0.15、end=0.55；接触区 max=0.45、hold=0.20、end=0.60；食物/缺口低频区 max=0.15、hold=0.10、end=0.45。hold/end 是去噪进度比例。VACE 固定 rigid_end=29、contact_end=28、material_end=12、hole_end=12。正式 VACE 未启用 noisy warm start；冻结配置中顶层 reason 的文字沿用了旧开发说明，实际任务参数和执行请求才是本次运行依据，原冻结文件不做事后改写。

所有正式配置、源码摘要、源图摘要、模型权重校验以及内部冻结时间存于 `formal/FROZEN.json` 与配套文件。它是执行前的内部冻结记录，不是第三方预注册。模型副本位于服务器本地磁盘，内容校验与原权重一致，避免网络文件系统的页读取等待。

## 评价与证据边界

每张原始输出分别判断：明显抬升、餐具承托、匹配源缺口、场景身份保持、没有人物、照片真实感。每项是通过/失败/不确定，六项全通过才算完整成功；不确定不算通过，没有输出算失败。餐具下方二维邻接不能证明真实三维支撑；缺口外观也不能证明确实来自同一个物理实体。

本轮主观检查由助手执行，属于诊断性视觉复核。没有独立人类评审，不能报告为盲评得分或人类偏好。另提供隐藏方法名的完整随机顺序图库和未填写的独立评审表。 部分输出将提示词中的叉子变成勺形或铲形餐具；用户目标是餐具承托，因此不单凭器型改变判承托失败，偏差记入逐图备注。餐具是否承托食物与餐具材质是否真实分别判断；可见接触仍可能与不真实的灰色叉子并存。

辅助指标是编辑区域外相对原图的 MAE/PSNR，以及 SAM3 独立文字提示（fork、tofu、hand）检测。检测时不使用目标框提示，目标掩码仅在推理后匹配食物连通块。SAM3 未在 8 张原图负对照上检出叉子或手，但这不等于证明生成图中不存在漏检，也不是普适特异度估计。未编辑原图即使背景指标很好，仍可能完全没有完成动作。

种子先在同一照片内平均，再汇总照片及保守场景簇。不能把 3 个种子或视频帧当作独立照片增加样本量。保留主集合和挑战集合分层，不作总体显著性或泛化承诺。正式矩阵完成后，预先指定 01/C/41 在两个后端各独立复跑一次，比较原图摘要和像素差；复跑不进入 192 个条件的分母。

## 执行过程中的技术修复

模型最初从 GlusterFS 网络挂载读取时出现长时间页读取等待。正式运行前将相同权重复制到服务器本地 ext4 磁盘，逐文件校验内容，保留约 129.44 GiB 的本次私有模型缓存。模型内容和正式参数没有因此改变。

首次监督进程误用了缺少 NumPy 的系统 Python，在启动生成任务前退出；随后使用已有 GeoEdit 环境启动，原始错误日志和修复记录保留。正式执行期间，收集器读取原子替换的清单曾遇到一次 ESTALE（失效文件句柄）；仅为清单读取加入有限次数重试，未修改生成脚本、输入、种子或参数。技术修复记录与正式失败样本分开保存，不能据此删除或替换任何正式条件。

## 配对比较与实际含义

先在每张照片的三个固定种子内求平均，再比较方法。Qwen C−A 为 −12.5 个百分点，C−B 为 +8.3，D−C 为 −4.2，D−A 为 −16.7，D−B 为 +4.2。按 7 个保守场景簇等权汇总，相应差值为 −14.3、+9.5、−4.8、−19.0、+4.8 个百分点。VACE 的完整通过差值全为 0。

C 相比 A 在 1 个簇改善、4 个簇变差、2 个簇持平；D 相比 C 没有改善的簇、1 个簇变差、6 个簇持平。C 相比 B 的改善只发生在 1 个簇，其余 6 个持平。由于样本有意筛选、只有 7 个簇、且只有一位未盲化助手复核，本实验不报告显著性检验、总体置信区间或论文式领先结论。11 类统计误读逐项检查记录在 summary.json。

作为补充敏感性检查，只看三维预处理成功的 7 张照片时，Qwen A/C/D 分别为 5/21、2/21、1/21，B 与 VACE 仍为 0。这不能替代主分析的完整分母，但说明当前排序并非仅由 06 的预处理失败造成。

第一项假设没有得到支持：当前 C 并未超过 A。C 对场景保持有帮助，但主要交换条件是直接编辑较容易完成动作、代理细化较容易保持构图，两者都常把“切取第一口”做成“额外添加一块食物”。第二项假设同样未得到支持：D 没有超过 C。Qwen 的照片真实感通过从 C 的 16/24 降到 D 的 7/24；VACE D 虽把对应缺口从 0 提高到 7/24，却有 21/21 已生成图未通过真实感。

## 问题定位与后续修改方向

1. **源缺口与目标食物的对应关系在生成后丢失。** 三维代理内部使用同一个实体切分，但将它压成 RGB 条件后，生成模型仍能把缺口补回，同时保留新增第一口。Qwen C/D 都只有 2/24 通过缺口标准。这说明内部体积守恒没有传递为输出图像的守恒；继续只增大抬升高度并不能解决它。
2. **几何结构与表面外观被绑在同一代理潜变量中。** 强制接近代理图也会强制保留平面切面、硬边和灰色叉子。VACE D 是最明显的例子：可以保住抬升与部分缺口，但没有一张同时达到照片真实感。
3. **单视图三维先验本身会产生错误目标视图。** 06 拟合失败，07 虽有较高原视图轮廓 IoU，抬升后却像矩形贴片。当前不确定指标不足，源视图拟合好不能证明目标视图可靠。
4. **当前数据只能检验外观可行性。** 没有同一食物真实切取前后的配对证据，所以不能据本次结果声称解决真实三维切取、物理支撑或身份守恒。

下一版应把源移除区域、剩余表面和目标第一口作为共同的显式对应变量；将轮廓/深度/法线的结构约束与材质生成分开；在进入扩散前检查目标视图是否退化。之后必须在新的保留源照片上重新冻结比较，不能用本轮 8 张反复调参后仍把它们当未见测试集。若要验证物理正确性，还需要少量真实切取配对、标定或扫描。以上是本次失败分析导出的待验证方案，本轮没有声称已经实现或证明它们有效。
