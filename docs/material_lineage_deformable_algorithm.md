# 材料身份约束的可变形食物编辑（MLD3）

这是此前 MLD2 完整实验后的算法扩展。目标是生成入口前、第一口明确离开盘面且由餐具托住的真实图片。此前算法已能控制切分和抬升，但隐藏三维先验弱，面条与松散食物被当作刚性块；完整算法必须包含拓扑分支、非刚性变形与接触，而不能只更换生成提示词。

本文描述实际可执行算法及评价口径。它不声明单图恢复了真实背面、物理质量、真实受力或通用照片级真实感。以前的全部失败与训练负结果保持原样。

## 1. 同一来源材料状态

给定原图 I、食物掩码 M 与推定相机 K，SAM3 给出可见语义区域，MoGe2 给出单目深度与相机假设。每个可见材料样本保存稳定身份 i、来源坐标 X_i、来源像素 u_i、来源颜色 c_i，以及重建代理权重 w_i。来源颜色是观测，而不是由生成器重新发明的食物。

MLD2 的已训练共享场提供来源状态的隐藏闭合/材料先验。它在 1024 个合成场景上有效，但此前真实图中经约束后作用有限；本轮继续把该角色限定为**受观测约束的来源先验**，不把算法化切分、来源纹理复制或解析接触的效果归给神经网络。

隐藏厚度 h_i 是一个受局部尺度、观测深度和形状约束限制的假设。可见顶部的深度起伏调整沿相机射线进行，保持顶部的来源投影；隐藏底面则沿推定食物法线偏移，其投影不是独立观测。闭合下界受推定局部盘面限制。所有隐藏材料只形成一个固定状态 H，后续切分、搬运、变形、回放都读取这个状态，不在不同阶段独立采样背面。最终16例中有6例的底面与统一厚度闭合的差异为零，学习先验在这些情况下被来源约束压制；本轮没有证明该先验在真实照片上优于解析闭合。

## 2. 先分配身份，再编辑几何

动作 A 指定来源切片/曲线选择、目标位置与餐具姿态。选中材料索引集 C、剩余集 R 从同一来源全集 S 得到：

    C ∩ R = ∅，C ∪ R = S。
    m_C = Σ(i∈C) w_i，m_R = Σ(i∈R) w_i。

这是来源重建代理的预算一致性，不是称量真实食物。源图缺口使用同一 C 的来源支持域；最终图中的被搬运材料也保持 C 的身份。不能一边生成一个新食物块、一边在源处挖一个没有对应关系的洞。

对于固体，来源局部网格闭合并切出第一口；对可见细条，来源曲线选择及其覆盖域决定实际移除区域，未选择食物继续保留。细条分支不能沿用固体的整块椭圆挖洞。

固体分支的修正默认值先检查**实际三角形邻接**，移除不构成面的孤立采样，保留最大的连通材料组件后再创建状态与全部动作对照。来源表面与隐藏闭合面之间的材料列保存显式顶面—底面索引对；厚度保持约束直接使用这些对应，不再通过浮点坐标相似性猜测配对。这是一口凝聚食物的显式拓扑先验；它不会把多个不相连的肉片自动变成一个物理整体。未被选取的原食物应继续保留在来源图。若要搬运多个松散组件，需要组件级接触与体积约束，不能让一个全局体积项把无支撑小岛拉成细柱。

## 3. 按观测拓扑选择力学表示

### 固体/片状食物：材料网格

保留网格顶点顺序、三角形、UV、颜色与材料身份。首先对第一口作同一刚性动作 Y_i^0 = T_A X_i。然后在目标餐具坐标中优化 Y，包含重力、形状/边长保持、局部平滑或弯曲，以及勺面不穿透约束。不同食物刚度影响形变幅度。

概念能量为：

    E(Y) = λ_e Σ_(i,j) (||Y_i-Y_j||-l_ij)^2
         + λ_b E_bend(Y, X)
         + λ_s E_shape(Y, Y^0)
         - Σ_i m_i g·Y_i
         + λ_c Σ_i max(0, -d_spoon(Y_i))^2。

实际实现可用投影式约束更新，不要求每项都有精确真实材料常数。动态节点质量 m_i 按网格面积集中或由曲线求解器规定；材料账本权重 w_i 则由重建体积与剩余可见列定义。二者角色不同，账本恒等式不能证明物理受力由真实质量驱动。质量、刚度与重力单位均属于模型设定。体积漂移用于检查代理形状稳定性，不能替代真实材料校准。

### 面条/细丝：来源可见曲线束

使用原图局部亮暗脊、方向一致性和连续性提取曲线，并由来源深度提升到三维。保存节点、相邻边、半径和来源 UV。提升后对曲线束施加弧长、弯曲、重力和勺面接触，使束可下垂而不是整块搬运。

新的通用选择先在来源图查询食材级 SAM3 面条掩码，再在保留域中提取脊。来源食物域为原选取掩码与可信 food 候选的并集，保存原选取域与扩展域。正向提示词固定为 noodles、pasta、noodle strands、soba noodles、udon noodles、ramen noodles、spaghetti；置信度至少 0.35、至少一半位于来源食物域的候选相交后合并。姜丝、鱼片/鲣鱼片、海苔、蔬菜、蛋、肉与餐具候选作为排除项，置信度至少 0.35 且覆盖正向域比例介于 0.001 与 0.65 时才扣除。food 并集候选另要求置信度至少 0.50、图像面积占比介于 0.006 与 0.88。保存原始查询、候选掩码、置信度、实际采用域与源图选择规则；这些是推定语义，而不是标注真值。所有面条案例采用相同规则，不能在看见最终取口后逐图挑选输出。来源第一口选择改变时，要重新查询同一冻结 MLD2 先验并固定新状态，再运行全部消融。

第一口的大小在来源图选择阶段确定。默认候选半径下界为图像短边的 0.085 与最小来源跨度的 0.60 两者取大，逐级扩大，优先选择最小且满足至少 24 像素跨度、36 像素累计可见曲线长度的来源束。不继承旧刚性块的取口半径，不在目标图放大假食物来满足可见性。没有足够来源曲线时保存不足状态；没有观测曲线时停止该细条分支。

被选曲线的来源移除域包含实际推定宽度和可见截面支持，不以最初候选椭圆硬裁去一半宽度；对应源处露出的背景/闭合仍是不确定假设。冷面 11 的黄色细条与配料身份尤其不确定，掩码剔除中心透明团块并不证明剩下的一定是面条。

这些曲线是**来源可见脊的拓扑假设**。单图无法确认遮挡部分的真实连接；鱼肉纹理、蛋卷褶皱和肉片也可能出现伪细条。因此必须保留非面条纹理控制及失败记录。不能把检测到的脊一律宣称为真实面条。

当前自动分支使用来源 SAM 文本提示中的食物词（noodle、ramen、udon 等）以及显式 `--material-mode`。这是来源类别提示驱动的路由，不是新训练的自动三维拓扑分类器。单张新图若只给出通用提示 food，会采用紧凑食物分支；不能据此声称任意食物都能自动识别。

节点在变形中保持身份、半径/来源颜色及来源 UV。只有空间位置改变。几何节点的来源坐标与纹理示例坐标分别保存：若几何坐标的双线性采样会混入排除食材，可改用附近合法纹理示例，但几何来源坐标保持原值，并报告示例偏移。每个纹理样本的所有非零权重双线性 texel 均须属于保留食材域；可见截面沿宽度采样遇到非法支持即截断，不跨越背景缝隙寻找另一段。曲线膨胀成可见细管是渲染表示，不代表推定了真圆截面。

本轮调试曾发现，初始推定细管的自碰撞松弛会在无重力时产生几乎同样大的位移，不能把这种位移算作重力效果。实际修正对来源中已重叠的非邻接推定细管记录歧义并排除其初始碰撞，而不是强行把来源解开；`source_ambiguous_overlap_pair_count` 必须保留。这处理了求解器启动混淆，**没有解决遮挡面条的真实拓扑或体积互穿**。

曲线中心线长度、半径构成的胶囊体积代理和实际渲染管状表面分别测量。后者需要连续截面框架并保存表面顶点身份；中心线不伸长不保证表面三角形不伸长，也不保证曲线束没有互穿。

## 4. 餐具接触是几何条件

勺子为一个具有厚度的闭合浅椭圆碗、颈部和有限长度的柄。椭圆碗内部的目标食物接触表面在勺面局部坐标中为：

    z_spoon(x,y) = z_0 + κ[((x-c_x)/a)^2 + ((y-c_y)/b)^2]。

最终协议使用公共 `spoon_surface.py` 定义餐具规划、求解接触和解析间隙。渲染器使用对应的 V3 餐具方程并采样为网格，二者的吻合由实际导出网格独立复核。颈部平滑连接碗面和略弯曲、渐变宽度的柄，接触域为椭圆碗与实际有限柄投影域的并集，不把整个半平面当作支撑。带符号间隙 d_spoon = z_food - z_spoon。负值代表穿入建模餐具上表面，接近零表示模型接触；域外不强制吸到餐具。该约束不等于真实受力验证。

独立评估额外读取实际导出的 `spoon.ply`，在餐具坐标中对真实上表面三角形做重心插值，重新计算碗、颈部与柄的间隙。它不复用求解器的解析高度函数，因此能检查渲染几何与接触模型之间的离散偏差。封闭边拓扑、朝向一致与源组件数量也分别记录；这些不等于排除了几何自相交。

重力和接触消融必须复用同一来源状态、同一切片、同一刚性动作和同一餐具姿态，分别去掉重力项或接触项，不能换图或重新选择更好的一口。

## 5. 先渲染材料运输，再做外观投影

被搬运顶部继续从来源 UV 采样颜色；侧面与背面从固定来源假设取材料。变形只运输同一材料，不把来源食物颜色交给自由生成器。相机与源相机保持一致，源处缺口、食物与餐具遮挡及阴影由同一状态计算。投影阴影逐个使用实际食物/餐具三角形，并将跨过推定接收面的三角形裁剪；只保留位于接收面上方的投影部分，避免一个全局凸包把面条间隙或已坠落材料连成假大阴影。接收面与光线仍是单图场景假设。

最终可选 Qwen-Image-2.1 + Fun ControlNet-Union 仅给出金属外观候选。冻结最终物理渲染图及其边缘控制，24 步、随机种子 41，不额外输入抬升前的来源参考图；生成编辑域为可见餐具扩张三像素后排除食物与源缺口。之后在候选图查询 SAM3 spoon/metal spoon，把检测域与冻结的实际可见餐具域相交，只复制原坐标上的相交金属像素。食物、源缺口及域外背景保留渲染/原图，未覆盖金属部分保留 PBR。独立评估实际最终图与物理渲染图之差，检查食物、可见餐具域外与接受域外是否出现任何改变。VACE 在本轮不参与。

本算法的原创实现是来源身份分配、观测约束状态、拓扑分支、变形接触和外观投影的整合。使用预训练模型或纹理运输本身并不自动构成经过文献验证的新颖性声明。

## 6. 执行输出与复现口径

输出根目录：`outputs/material_lineage_deformable_20261004`。每个 `real/real_XX_ID` 保存：

- 原图 `source.png`；同动作刚性基线 `rigid.png`；完整求解 `deformed.png`；最终受限外观 `final.png`。
- 消融 `no_contact.png`、`no_gravity.png`；实际声明编辑域 `edit_mask.png`；目标食物域 `moved_food_mask.png`；来源食物/取口域 `source_food_mask.png,source_removed_mask.png`。
- `state.json` 保存分支、相机/动作、餐具、刚度/求解设置、模型角色与假设。
- `transport.npz` 保存来源身份、切分身份、稳定顶点、UV、材质、权重、四种动作下的坐标、边/面、真实执行接触间隙。

当前来源身份全集由选中材料的网格/管状顶点与未移除的来源可见列组成；身份和权重在求解中固定。这是操作代理的离散化，不是来源全部真实粒子的标识。集合预算必须与来源掩码、移除掩码和来源 UV 覆盖检查共同阅读，集合恒等式本身不能证明选取了正确的真实物质。

相对刚性基线的全部位移需分成质心沉降与减去质心后的形变；自由下落可以产生很大整体位移，但不是食物形变。两者分别报告，不能把去接触后的整体坠落算作非刚性能力。

服务器单图完整执行命令（该服务器封装绑定现有运行环境与冻结权重）：

    bash scripts/run_mld3_gp40.sh --image /path/food.png --food-prompt "udon noodles" --output /path/results --appearance

已有观测缓存的全图协议用 `--input-root /path/observations` 替代 `--image`。`--appearance` 添加受限餐具外观阶段；省略时最终图保存物理渲染结果。脚本没有独立的 `--selection` 参数。来源语义提示决定默认材料分支，可显式选择 `--material-mode`。这轮未训练新的通用食物变形网络；MLD2 65k checkpoint 为冻结的来源先验。

独立评估命令：

    python scripts/evaluate_mld3_integrated.py --root outputs/material_lineage_deformable_20261004
    python scripts/build_mld3_gallery.py --root outputs/material_lineage_deformable_20261004

必需数组：`source_id, carried_ids, remaining_ids, target_ids, rest_xyz, rigid_xyz, target_xyz, no_contact_xyz, no_gravity_xyz, edges, faces, source_uv, target_source_uv`。

可报告来源代理预算的数组：`material_mass` 与 `source_id` 同长度。材质检验：`source_material_rgb,target_material_rgb` 对应稳定搬运顶点。接触数组：`{rigid,target,no_contact,no_gravity}_support_gap` 及对应 `_support_inside`；域外顶点不计勺面间隙。可选 `camera_intrinsics` 计算目标投影位移。

来源 UV 约定：固体保存像素中心（整像素索引 + 0.5）；曲线保存双线性图像采样索引坐标，渲染器加入 0.5 转为像素中心。UV 恒等检查始终比较相同约定下的来源与目标数组。除最邻近掩码覆盖外，评估独立检查所有非零权重双线性 texel 的来源食物、移除域及细条食材域所有权。

细条额外保存 `strand_node_source_uv,strand_node_texture_exemplar_uv,strand_curve_offsets`，前者是几何观测来源，后者是合法纹理示例；二者的偏移单独报告。`source_uv,target_source_uv` 对应稳定渲染顶点的纹理坐标。实际几何投影运动从 `rest_xyz` 与 `target_xyz` 投影差计算，不能把示例偏移误算成抬升。

UV 是来源纹理坐标，不能自动等同于独立物质所有权。隐藏圆管背面会重复可见截面的纹理，跨截面样本可能来自选择域边缘；如果来源移除域裁掉了被选择曲线的实际宽度，必须扩展对应来源支持域，或把这些样本明确限定为纹理示例。不能只凭新建的序号集合就宣称真实物质已精确分配。

每个变体保存自己的 `rigid_edit_mask.png,deformed_edit_mask.png,no_contact_edit_mask.png,no_gravity_edit_mask.png`，背景差异相对该变体实际声明的编辑域计算。最终图用 `edit_mask.png`。额外的 `source_food_mask.png`、`source_removed_mask.png` 和 `remaining_source_uv` 支持来源覆盖检查。评价实际重力作用后的源法线抬升，而不只报告预设刚性平移。

## 7. 完整实验的结束条件与不成立条件

完整算法执行完成需：全部 16 来源图保留；固定来源状态下刚性/完整/去接触/去重力四路均生成；可见抬升与对应缺口由实际图像检查；稳定身份和来源 UV 的实际数组检查；刚度、接触、重力的作用可由消融数值与图像核对；逐例视觉失败由根代理实际查看后记录。

另外用固定来源形状和不同动作/餐具姿态验证求解器响应，包含紧凑固体、柔软薄片、可见细条与非细条纹理控制。各动作不会增加独立真实样本数；同图调参后结果不称为盲测。

不成立或只能部分成立的情况必须保留：材料被新增/遗漏；UV 丢失；域外图像变化；接触穿透仍大；边长/代理体积失控；细条误检测；去掉约束没有任何可测作用；源缺口与被取材料不对应；金属外观改动食物；看起来仍为硬块、管状伪面条或 CG 切面。

## 8. 初轮实际检查与修正原因

首轮完整 16 图的图像、数组和报告已保留为初轮证据，后续修正不删除它们。

- 来源三角化存在孤点/小组件：02、04、15 各有两个未被三角形引用的顶点。它们进入求解和阴影凸包后坠落到约 −3.8 来源尺度，不能把它们过滤出统计后宣称修复。15 另有 10 顶点的小闭合组件，只有一个顶点进入勺面；全局体积约束加局部接触使一条边伸长约 1244 倍。须在来源切分前处理三角化连通性，或者对真实松散组件独立求解，随后重建身份、移除域与全部对照。
- 原细条选择在 10 拿到了红色配菜而不是主要面条。来源纹理复制和预算恒等式不能修复语义选错。应尝试来源食材级掩码与相同的通用选择规则，并保留分割分离失败。
