## 问题与可检验修改

v3 在玉米上出现白边和旧位置亮斑，未加约束的同状态输入更自然。v4 撤销背景潜变量恢复与最终像素贴回，只对距食物边缘较远的内部施加软约束。目标是检验是否能保留内部细节，同时让边界、勺具、阴影和整体亮度由同一个生成过程协调。

v4 不估计真实材质或光照。距离边界是置信度的启发式替代；潜变量的高通分量不等同于物理反照率。保留食物的内部由同一个源图矩形中的 GrabCut 分割获得，不使用配对目标。

## 固定条件

两张已见真实开发图 pizza/corn，seed=281、40 步、CFG=4、1184×896。输入 reference.png 与提示词和 v3 逐字节相同；离线模型与 pipeline 版本也相同。v3 scaffold_only raw 和 v3 projected raw 是已有对照，不重新挑选或生成它们。

共同修改：

1. 食物边缘内 12px 权重为零，12–24px 平滑增加至 1；保留搬运食物和其他食物的内部，原处移除区域权重为零。
2. 背景完全由模型生成，不对它施加逐步像素或潜变量恢复。
3. 约束最大强度 0.8；最后四分之一步骤线性减小，最终一步为零。
4. 只交付原始模型生成，取消硬贴回和泊松融合。因而不再宣称最终复制误差为零。

两个新条件，各两次生成：

- interior：内部的全部参考潜变量软约束。
- detail：只约束内部参考与当前潜变量差值的高通分量；以 5×5 均值滤波定义低通。允许空间上均匀的潜变量变化，不将其冒称为真正的亮度/纹理解耦。

令下一步噪声水平的参考为 `known`，内部权重为 `C`，时间强度为 `a(t)`：

`interior: z <- z + a(t) C (known - z)`

`detail: z <- z + a(t) C [(known - z) - G5(known - z)]`

本批总计 4 次模型调用，不更换 seed、不在查看输出后修改参数。查看全部 raw 结果，重点检查玉米白圈/旧位置亮斑、披萨形状/配料、其他食物、工具与相机布局。源处局部 MAE之外，追加固定扩展区域诊断以覆盖旧阴影；这种新增诊断不能与过去不同区域的指标混为一谈。
