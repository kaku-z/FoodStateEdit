## 可见结果：作者侧非盲检查

| 条件 | 披萨 | 玉米 |

| Original raw | 原处披萨基本移除，但目标位置偏离指令、勺柄向下而非左下；食物轮廓和配料布局被重绘 | 原处移除，出现单勺承托；位置偏左、勺柄向下而非右下 |

| Grounded raw | 原处披萨仍在；目标块被旋转，出现重复 | 原处移除，单勺与目标位置视觉上较合理 |

RGB MAE 为 0–255 像素单位，越小越接近配对参考；仅在固定源掩码内计算。

|---|---:|---:|
| 不编辑的源图 | 83.13 | 42.33 |
| 粗状态图（Telea 修复，无真实勺具） | 14.83 | 23.84 |
| Original raw | 38.70 | 2.06 |

这只能评价原食物占据区域与配对餐盘的差异：错位工具及阴影也可能进入该区域，不能用它单独判断是否移除了食物，更不能给整体托举质量排名。掩码、边缘误差、曝光及相机差异都是混杂因素；此处没有配准或颜色校准。配对参考与源图在保护区的 MAE 分别为 2.67 和 1.97，作为事后诊断记录于 `reference_diagnostics.json`，不从主指标中相减。

所有 localized 版本的保护区差异为 0、observed_locked 的内部复制误差为 0，均由合成公式保证，只是工程检查。两个 locked 版本的源处误差与 Grounded 相同，也由它们只改目标块决定。不能将这些零误差或重复数值作为新增科学证据。

## 失败机制与下一次开发应检验的修改

1. **状态没有约束生成过程。** 模型同时看到原图与状态图，仍可从原图恢复旧位置的披萨。唯一来源编号只在合成器中生效，不能约束模型生成多少块食物。
2. **生成几何与固定输运不一致。** 模型可转动或重画目标食物；事后贴回平移后的原纹理会形成两套轮廓。6 个颜色参数无法修正这个问题。
3. **允许区域边界缺少一致性条件。** 全图生成改变餐盘光照，硬保护区却保留原图，局部替换产生色块。给食物做亮度适配不能处理餐盘边界。

后续候选修改应采用分层状态约束：先独立生成无目标食物的餐盘层；食物层的来源、轮廓与目标变换贯穿推理；工具/阴影层按固定支撑位置生成；在实际去噪阶段或等价的区域生成机制中限制可变区域，并对边界颜色连续性设置约束。开发时分别消融「餐盘层」「生成内形状约束」「边界连续性」，复用这两张失败图，固定每支生成预算，不能用更换图片掩盖反例。

以上是由本轮失败导出的**待实现方案**，没有在本报告中冒称已完成或有效。单纯增加模型大小、采样次数或重试选图，都不能替代对上述机制的验证。
